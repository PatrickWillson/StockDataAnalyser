## 1. What it is

A CLI that takes a ticker (`SYMBOL.EXCHANGE`, e.g. `AAPL.US`, `YU.LSE`, `RY.TO`), pulls fundamentals from EODHD and prices/FX from yfinance, computes Benjamin Graham valuation metrics and investor tests, and writes a fixed-format Markdown dossier to `data/{TICKER}_DOSSIER.md` (dots → underscores) for LLM consumption.

```
python stock_data_analyser.py AAPL.US [--debug]
```

Requires `EODHD_API_KEY` in `.env`. `--debug` sets DEBUG logging and dumps raw EODHD JSON to `data/{ticker}_raw_api_response.json`.

**Secrets in logs:** the EODHD key travels as the `api_token` query parameter. `configure_logging` keeps urllib3 at WARNING (its DEBUG output prints full request URLs) and attaches `logging_utils.SecretRedactingFilter` to every root handler, which replaces `api_token=…` values and the literal key with `***` in messages and tracebacks. Guarded by `tests/test_log_redaction.py`. Handlers added to the root logger *after* `configure_logging` do not get the filter.

## 2. Pipeline (what `main()` does, in order)

| Step | Code | What happens |
|---|---|---|
| 0 | `stock_data_analyser.py` import time | `load_dotenv()`; `API_KEY` read into a module global |
| 1 | `main()` | argparse (`ticker` upper-cased, `--debug`); the fundamentals provider from `FUNDAMENTALS_PROVIDER` (default `eodhd`; unknown → exit 1) and the environment variables it declares (`required_env`, e.g. `EODHD_API_KEY`; any missing → all named, exit 1); `configure_logging(debug, secrets=<its secret_env values>)` (urllib3 logger pinned to WARNING; `SecretRedactingFilter` on root handlers); exit 1 if no key |
| 2 | `ClientFactory` (`clients/factory.py`, the composition root) | `create_fundamentals_source(env, provider)` → `EODHDClient`; `create_quote_source()` → `YFinanceClient`; `create_rate_source()` → `FXClient` — one adapter per port (`core/ports.py`) |
| 3 | `core.financial_data_assembler.load_financial_data(ticker, fundamentals_source, quote_source, rate_source)` | `fundamentals_source.fetch_fundamentals(ticker)` (EODHD: fundamentals + dividend endpoints, mapped by `clients.eodhd_mapper.to_fundamentals` into a provider-neutral `CompanyFundamentals`, `core/fundamentals.py`; free path: SEC EDGAR + Yahoo via `FreeUSFundamentalsSource`, §12); `quote_source.get_quote(ticker)`; then `core.financial_data_assembler.FinancialDataAssembler.assemble(fundamentals, ticker, quote)` normalises, currency-normalises, calculates and validates → `financial_data` dict (§4.1); data-quality warnings include `validate_data_quality` and `check_data_staleness` (latest annual report > 9 months old; dividend-only years ignored) |
| 4 | `main()` + `core.historical_prices.apply_year_end_prices` | CLI fetches daily prices from the quote source and matches them to fiscal year-ends; `apply_year_end_prices` divides minor-unit prices by 100 (per `price_quote_currency`, e.g. GBp), applies historical FX (current-rate fallback), writes `history[date]['year_end_price']` and adds warnings; `main()` then freezes `financial_data` into a `FinancialData` (`core/models.py`) |
| 5 | `GrahamCalculator(financial_data).compute()` | → `metrics`, a `GrahamResult` (`core/models.py`) built from the `compute_all()` dict (§4.3). TBVPS, normalized Graham Number and EPV are computed once and passed to the Graham Number, margin of safety and investor tests (each public method still computes them itself when called alone) |
| 6 | `TTMCalculator(quarterly_data, price, currency).compute()` | only if `quarterly_data` present; wrapped in try/except → `ttm_metrics`, a `TTMResult` (§4.4). Its warnings, a failure message or "Periodic data not available" are added to the model's `warnings` (`dataclasses.replace`) before steps 7–8 |
| 7 | `AnomalyDetector(financial_data).scan()` | → `anomalies: List[str]` |
| 8 | `DossierGenerator(ticker, financial_data, metrics, anomalies, ttm_metrics).generate()` | → Markdown string |
| 9 | `save_dossier` | writes `data/{TICKER}_DOSSIER.md` (path relative to CWD) |

Error handling: clients and the assembler raise typed errors from `core/errors.py` (`DataSourceError` → `SourceAuthError` (401), `SourceRateLimitError` (429), `SourceRequestError` (network / other status / bad JSON), `PriceUnavailableError` (no usable price from the quote source)); the EODHD adapter raises subclasses `EODHDAuthError` / `EODHDRateLimitError` / `EODHDRequestError` (`clients/eodhd_client.py`); no client calls `sys.exit`. `main()` catches `PriceUnavailableError` (fatal banner + troubleshooting), other `DataSourceError` (message) and any other `Exception` (critical), each → exit 1. Exit codes are only 0/1.

the 'per-share figures N/A' note only for years still without a share count; filer scale errors: a value exactly 1,000x or 1,000,000x below another filing's for the same fact is dropped; filed EPS exactly 100x or 1,000x net income / weighted-average shares is divided back (DRDGOLD: cents tagged as rand), 1/100 or 1/1,000 of it is left (the average shares are in thousands), and any other gap over 10% is noted with the filed figure kept (EPS below 0.10 is not checked); and a share count 1,000x below the company's median year is multiplied by 1,000 (noted); preferred stock = max(carrying value, liquidation preference); operating cash flow = NetCashProvidedByUsedInOperatingActivities, else …ContinuingOperations; latest filed value per year (restatements, GRAHAM_METHODOLOGY §8.7) with first-reported → latest differences in the notes; the most recently filed tag of a chain wins, ties by chain order; revenue prefers sales-type tags (D-F3) except utilities (SIC 49xx: `Revenues`); ### 4.2 `history` row (built by `FinancialDataProcessor.merge_financial_data`; statement fields come from `core.fundamentals` rows via `as_history_fields()`)
`revenue, net_income, eps, dividend, total_equity, intangible_assets, goodwill, current_assets, current_liabilities, total_liabilities, long_term_debt (None = borrowings reported but no long-term debt identified — edgar_mapper BORROWINGS_EVIDENCE: debt-instrument, borrowings, bonds, loans, non-current financial liabilities and subordinated debentures (Royal Bank of Canada) tags —, `BalanceSheetRow.long_term_debt_unknown`: debt tests not met, NCA debt coverage N/A, Risk Factors "not identified"; GRAHAM_METHODOLOGY §8.9), total_assets, total_debt, inventory (None = not reported), claims_outside_equity (minority / redeemable equity), preferred_stock (inside equity; 0.0 when none), shares_outstanding, wcps, payout_ratio, year_end_price`, and `operating_cash_flow` (only on statement years whose cash flow was reported and, when the cash-flow currency differs, converted; added by `FinancialDataAssembler._attach_operating_cash_flow`, display only)

- Missing numbers are **0.0** (via `sanitize_value`, which also maps JSON null, `"NA"` and non-numeric junk to 0.0), not None. `wcps` is `"N/A"` with no shares or no balance sheet for the year (an income-only year: working capital unknown, not zero); `payout_ratio` is a formatted string (`"12.3%"`, `"0.0%"`, `"N/A"`); `year_end_price` may be None.
- Keys are fiscal year-end dates; `dividend` sums the payments dated inside that fiscal year (`core.history.fiscal_year_of_date`; outside the reported years the usual year end decides). **Dividend-only years** (dividend data exists but no statements, often the current/future year) are synthesised with the latest FYE month-day and all statement fields 0.0.
- Shares priority (malformed `outstandingShares.annual` rows are skipped individually): `outstandingShares.annual` → BS `commonStockSharesOutstanding` / `weightedAverageShsOut` / `...Dil` → `SharesStats.SharesOutstanding`.
- EPS: API `eps`/`basicEPS`/`epsBasic`; if 0, fallback `net_income / shares`. Net income = `netIncomeApplicableToCommonShares`, else `netIncome` (earnings for the common, special items included, after minority interest; GRAHAM_METHODOLOGY §2.3). `netIncomeFromContinuingOps` is never used: EODHD reports it before minority interest. Real EODHD income statements carry no `eps` field (WLKP.US), so EPS normally comes from the fallback.
- Total debt: reported `shortLongTermDebtTotal` (short + long-term debt incl. leases) when > 0, else `longTermDebt + shortTermDebt` (GRAHAM_METHODOLOGY §9). Display only (history table, Risk Factors "short-term debt and leases" = total − long-term); Graham's debt tests use `long_term_debt`.

## 5. Calculations

### 5.0 Data-source principle
Calculations use only **raw** EODHD statement line items (revenue, net income, equity, liabilities, share counts, dividends paid) plus market prices and FX rates. Every ratio and per-share value is derived here from annual audited data. EODHD pre-computed values are opaque (forward vs trailing, quarterly vs annual) and may only be shown as clearly labelled comparisons or display-only market data.

Where EODHD pre-computed values are used today:

| EODHD value | Current use | Complies? |
|---|---|---|
| `PERatio`, `ReturnOnEquityTTM`, `ReturnOnAssetsTTM`, `ProfitMargin` | Read, then overwritten by our own calculations; API values only in cross-validation warnings | Yes |
| `Highlights.BookValue` | Shown only as "API BVPS" comparison in Calculation Details | Yes (labelled comparison) |
| `Beta`, `52WeekHigh/Low`, `PercentInsiders/Institutions` | Display; Beta also drives a Risk Factors band | Display-only market data |
| `DividendShare`, `DividendYield`, `EnterpriseValue` | Read, never used | Unused |
| `ForwardAnnualDividendRate` (estimate) | Display only: the Executive Summary "Forward Rate" yield (labelled). Never in `history`; Risk Factors payout/coverage use the latest fiscal year's audited dividend per share (F21) | Yes |
| `NumberDividendsByYear` (payment counts) | Last-resort dividend *record* only (`is_dividend_amounts=False`): shown as "Div Count", counts as "paid" in the dividend-record tests; never FX-converted, never a payout ratio, yield or per-share amount (F21) | Yes |
| `MarketCapitalization`, `SharesOutstanding`, `SharePrice`, `LastPrice` | Never used for the price (removed by F21: yfinance is the only price source) | Yes |

`SharesStats.SharesOutstanding` (a raw current share count) is the last-resort share count for years without an annual figure.

### 5.1 Graham (`core/graham_math.py`, `GrahamCalculator`)
"Latest financial year" = first year (newest first) passing a `core.history` predicate. Four variants exist, each defined once there and kept distinct on purpose (unifying them would change output): `has_statement_data` (revenue>0 or net_income≠0 or equity>0 — used by most code), `has_statement_or_current_assets` (`_get_latest_financial_year`), `has_balance_sheet_data` (current ratio), `has_income_data` (20-year table). `net_income_known` (net_income≠0: the history stores an unreported figure as 0.0) gates the EPV years. `is_dividend_only_year` (statement fields all present and zero, EPS 0) is the stricter rule used by `extract_3year_eps_data` (F2) and `check_data_staleness` (F11).

| Metric | Formula / rule |
|---|---|
| TBVPS | (Equity − Preferred − \|Intangibles\| − \|Goodwill\|) / Shares (`core.formulas.tangible_equity`; preferred = history `preferred_stock`, 0 when none); negative → "N/A" + warning. BVPS and P/B use common equity = equity − preferred (`common_equity`); ROE stays on total equity |
| Graham Number | √(22.5 × EPS_latest × TBVPS); EPS ≤ 0 → "N/A" |
| Normalized Graham Number | √(22.5 × mean(EPS of the 3 most recent years with statement data) × TBVPS) — uses `FinancialDataProcessor.extract_3year_eps_data`, which skips dividend-only years (revenue, net income, equity all 0.0 and EPS 0); same years as the 3-yr avg P/E |
| Net-Net (NCAV/share) | (Current Assets − Total Liabilities − claims outside common equity) / Shares (`core.formulas.net_current_asset_value`). Claims = the larger of the minority-interest field and total assets − total liabilities − equity, floored at 0 (`BalanceSheetRow.claims_outside_common_equity`). Annual and TTM. Preferred stock inside equity is deducted too (EODHD: §11 E10 pending) |
| NCA details | NCA = working capital = CA − CL (as in the defensive debt test 4.2); debt coverage = LTD / NCA; keys `current_assets, current_liabilities, nca, long_term_debt, debt_coverage_ratio, debt_coverage_pct, warnings`. Shown in Key Metrics; the latest financial year without balance-sheet data (an income-only year, e.g. a Yahoo year filled from Eulerpool) → all "N/A", not 0.00. Not the net-net value (CA − all liabilities − claims) |
| Current ratio | CA / CL for the latest year with balance-sheet data; `{'ratio', 'fiscal_year_end'}`; shares `investor_tests.criteria.latest_current_ratio` with the current-ratio investor tests, so display and PASS/FAIL agree |
| Quick ratio | (CA − Inventory) / CL from the latest annual balance sheet (`inventory` parsed; a reported 0 counts). Inventory not reported → N/A with a warning, never imputed from the sector (F14) |
| 3-yr avg P/E | price / mean(EPS of 3 latest complete years) |
| Combined P/E×P/B | round(P/E) × round(P/B, BVPS-based) ≤ 22.5 |
| EPV | mean(net income, up to 10 complete years whose net income is known, min 7) / COST_OF_CAPITAL (a year with other statement data but net income 0.0, i.e. unreported, is left out, not averaged as zero: `core.history.net_income_known`); per share = mean(each year's net income / max(latest reported year-end count, that year's count, else the nearest later year's)) / COST_OF_CAPITAL (`graham_math.per_share_on_present_capitalization`; Security Analysis ch. 39, GRAHAM_METHODOLOGY §2 rules, 2026-11-09; `normalized_eps`, `eps_values`, `share_basis`: the counts used, years on their own larger count, rises over SUBSTANTIAL_SHARE_CHANGE 10%), floored at 0; no share count in the window → `epv_per_share` "N/A" with `epv_per_share_reason`. Unavailable (fewer than 7 complete years, no data) → `epv`/`epv_per_share` "N/A" with `unavailable_reason`; negative average earnings over the cycle → 0.0 (no earning power), also with the reason (F3) |
| Margin of Safety | IV = min(Normalized GN, EPV/share) over the anchors that are available; MoS = (IV − Price)/IV × 100; IV 0 (no earning power) or both unavailable → "N/A". `margin_of_safety_details['note']` gives the reason when an anchor is missing or IV is 0, and the Executive Summary shows it |
| Verdict | `core.verdict.determine_verdict` (D8), first match: `annual_report_age_months` over 18 → INSUFFICIENT DATA; price ≤ ⅔ × NCAV/share → NET-NET BARGAIN if the latest year's net income is positive and (NCAV/share − price) ÷ last year's fall in NCAV/share ≥ 2 (or it did not fall), else UNDERVALUED – FAILS GRAHAM CRITERIA; no intrinsic value → INSUFFICIENT DATA; MoS ≤ 0 or N/A → OVERVALUED; all defensive PASS → DEFENSIVE BUY; all enterprising PASS → ENTERPRISING BUY; else UNDERVALUED – FAILS GRAHAM CRITERIA. "N/A" never counts as a pass. `metrics['verdict_reason']` names the rule and failed criteria; the Executive Summary shows it |

**Defensive tests** (`DEFENSIVE` thresholds): current ratio ≥ 2.0; LTD ≤ CA − CL (no CA and no CL reported → FAIL, also for the enterprising test); earnings stability (positive NI in last 10 years); dividend record (a dividend in each of the 20 fiscal years ending with the newest year; fewer years or a missing year → FAIL); earnings growth (mean EPS of reported years 0–2 ≥ 4/3 × mean EPS of years 9–11; a year in either window with net income but EPS 0 (`core.history.eps_unknown`: vendor years with no share count) → "N/A (EPS unknown)"; fewer than 12 reported years → "N/A (Too Young)"); P/E: price ≤ 15 × mean EPS of the 3 latest reported years (`extract_3year_eps_data`; fewer years or average ≤ 0 → FAIL); Public utilities (`General.Industry` in `REGULATED_UTILITY_INDUSTRIES`: regulated electric / gas / water): current ratio "NOT APPLICABLE (public utility)" (left out of the verdict) and debt test total debt ≤ 2 × stockholders' equity (long-term debt unknown → FAIL, §8.9); `metrics['public_utility']`. P/B: price ≤ 1.5 × tangible BVPS, or P/E (3-year average) × P/B (tangible) ≤ 22.5 (`defensive.pe_pb_multiples`, also behind `metrics['combined_pe_pb_test']`).
**Enterprising tests** (`ENTERPRISING`): current ratio ≥ 1.5; LTD ≤ (CA − CL) × 1.10; earnings stability (5 of last 5); current dividend > 0; earnings growth (latest EPS > EPS 5 reported years earlier; fewer years → FAIL; either EPS unknown (`eps_unknown`) → "N/A (EPS unknown)"); price: P/E < 10 AND price < TBVPS × 1.20.

### 5.2 TTM (`core/ttm_calculator.py`, `TTMCalculator`)
1. `TTMCalculator(quarterly_data, price, currency)` uses the price exactly as given (already normalised in core — no second London Fix). Periodic statements are in the financials (= unified) currency, so there is no conversion and `quarterly_data` is never modified.
2. `detect_reporting_frequency`: **median** interval of last ≤5 income dates — 75–105 d quarterly, 150–210 d semi-annual, else irregular (TTM aborted).
3. `_select_periods_for_ttm`: 4 quarters or 2 halves; gap check (any interval > expected + tolerance, i.e. > 120 d quarterly / > 225 d semi-annual, aborts TTM); span check (quarterly 225–315 d, semi 150–210 d).
4. `calculate_ttm_metrics`: sum revenue/NI over periods; balance items from the balance sheet dated at the latest selected income period (else the latest one, with a warning); TTM EPS = ΣNI / latest shares.
5. TTM TBVPS / Graham Number / Net-Net / MoS (MoS uses TTM Graham Number only) / P/E / P/B.
6. `DossierGenerator` shows the TTM section only if `ttm_graham_number != "N/A"`. The section compares TTM Graham Number, TBVPS (`metrics['tbvps']`), net-net, P/E and P/B (`financial_data['pe_ratio']`, `['price_to_book']`) with the latest annual figures; the TTM margin of safety is shown with its basis, not diffed (the annual one is defined differently).

### 5.3 Anomalies (`core/anomaly_detector.py`)
YoY EPS growth % between consecutive years with income data within the table's latest `FINANCIAL_HISTORY_YEARS` (20) years (dividend-only placeholder rows skipped; prev EPS ≤ 0 skipped). Modified Z-score 0.6745 × (x − median) / MAD with MAD floored at `ANOMALY_MIN_SPREAD_PP` (1 pp), flagged when |z| > 3.5 (Iglewicz & Hoaglin; NIST e-Handbook §1.3.5.17). Needs ≥ 3 growth rates. Data-quality alert only, not a Graham criterion.

## 6. Currency handling

1. Trading ccy = `General.CurrencyCode`; financials ccy = balance-sheet `currency_symbol`; unified = financials.
2. Dividends: `try_convert_batch` to financials ccy at **current** rate; the "Could not convert dividends" warning is added only when it returns None (no FX rate).
3. Price: `EODHDClient.fetch_all_data` fetches the yfinance `PriceQuote` (I/O); `FinancialDataProcessor.get_current_price(quote, trading_ccy, warnings)` accepts it only if the price is positive **and** the quote currency matches EODHD's `General.CurrencyCode` (`same_currency`, any unit); otherwise it returns a reason and the assembler raises `PriceUnavailableError` (no EODHD price fallback: no price, no dossier). No I/O in core. Then:
   - unit from the **quote currency code** (F6): minor unit (GBp/GBX, ZAc, ILA) → ÷100 to the major currency (London Fix for GBP), logged in the conversion history; no P/E heuristic. EODHD's 52-week range is divided the same way (same exchange prices, same unit)
   - then convert to financials ccy; `fx_rate_used` recorded; historical FX fetched for fiscal year-ends.
4. Highlights dividend/BVPS, forward dividend, TTM dividend: GBX relabelled GBP, then converted (dividend and book value each on their own, F10). The BVPS cross-check compares the converted `Highlights.BookValue` with equity / shares, both in the financials currency.
5. `core.historical_prices.apply_year_end_prices` converts historical year-end prices: same Yahoo listing, so the quote's unit applies (÷100 for a minor unit, falling back to EODHD's trading code when `price_quote_currency` is absent), then historical FX with current-rate fallback.
6. Executive Summary treats the 52-week range as `price_currency_before_fx` and converts it with `fx_rate_used` (the rate already used for the price); no FX calls happen in the output layer.
7. All conversions are logged into `warnings` via `CurrencyConverter.get_consolidated_warning()`.

Price-unit logic lives in `core/price_quote.py` (`is_minor_unit`, `to_major_unit`). Other GBX logic: `CurrencyConverter.convert` (÷100), `FXClient.get_rate` (GBX treated as GBP, no factor), `convert_batch` (no special case), the assembler, `core.historical_prices`. Change one → check all.

**GBX units (verified against 30 real LSE dossiers in `data/`, 2026-10-31):** EODHD reports LSE *prices* in pence but dividend amounts (Dividend API `value`, Highlights `DividendShare`, `ForwardAnnualDividendRate`) in **pounds** even when labelled GBX (e.g. ABF: £0.90 trailing at £18.73; YU: £0.56 at £17.40). Hence prices are ÷100 while dividend paths treat GBX as GBP with no factor — do not "unify" them.

## 7. Price & exchange mapping

- `YFinanceClient.EXCHANGE_MAPPING` maps EODHD exchange codes → Yahoo suffix (US/NYSE/NASDAQ → '', LSE → .L, TO → .TO, XETRA → .DE, AU → .AX, HK → .HK, …; SAU → .SR, IL → .IL; 53 entries). Unmapped → bare symbol (warning); safe only because the quote currency must match.
- `_parse_ticker` splits on the last dot (`BRK.B.US` → `BRK.B`, `US`); `_translate_ticker` turns symbol dots into dashes (`BRK-B`, `BT-A.L`).
- Historical prices: `history(start, end, auto_adjust=False)` → `Close`, split-adjusted but **not** dividend-adjusted (F8); matched to fiscal year-ends with a 7-day backward window (`match_fiscal_year_end_prices`; FX uses an identical `match_fiscal_year_end_rates`).

## 8. Dossier

`DossierGenerator.generate()` renders in the CLAUDE.md order (D3, F15):

| # | Heading | Source |
|---|---|---|
| – | Header (`# STOCK ANALYSIS DOSSIER`, DATE, CEO/sector/currency) | `header.py` `HeaderSection(ticker, financial_data)` |
| 1 | EXECUTIVE SUMMARY | `executive_summary.py` `ExecutiveSummarySection(financial_data, metrics)` |
| 1.5 | TTM ANALYSIS (conditional) | `ttm_analysis.py` `TTMAnalysisSection(ttm_metrics, metrics, financial_data)` |
| 2 | KEY METRICS | `key_metrics.py` `KeyMetricsSection(financial_data, {'current_ratio': …, 'quick_ratio': …, 'nca_details': …})` |
| 3 | CRITICAL ALERTS | `critical_alerts.py` `CriticalAlertsSection(financial_data, metrics, anomalies)` (warnings + anomalies) |
| – | RISK FACTORS | `risk_factors.py` `RiskFactorsSection` (`generate()` → `_generate_second_risk_section`) |
| 4 / 5 | GRAHAM DEFENSIVE / ENTERPRISING TESTS | `graham_tests.py` `GrahamTestsSection(metrics)` |
| 6 | 20-YEAR FINANCIALS | `financial_history.py` `FinancialHistorySection(financial_data)`; Total Debt N/A in a year whose long-term debt is unknown (`long_term_debt` None, §8.9) |
| – | METHODOLOGY NOTES | `methodology.py` `MethodologySection` |
| – | CALCULATION DETAILS | `calculation_details.py` `CalculationDetailsSection` |

Every section subclasses `DossierSection`, receives the shared `core.report_context.ReportContext` (or builds it when constructed alone), and its `generate()` returns `List[str]`; `DossierGenerator.sections()` is the ordered registry and `generate()` joins all their lines with `\n`. Money amounts are formatted with `output.formatting.format_price_display` (one shared definition), and inline amounts use the same amount-then-code style (`29.11 USD`, `1,234 GBP`). Sections only format: derived values (BVPS, NCA, ratios, yields, risk figures) come from the view model or core results. Criterion and formula text in Graham Tests, Methodology and Calculation Details is built from config (`GRAHAM_MULTIPLIER`, `COST_OF_CAPITAL`, `DEFENSIVE`/`ENTERPRISING`, `EPV_MIN/MAX_YEARS`).

## 12. Data sources: ports and adapters (replacing a vendor)

The core never talks to a vendor. It depends on three **ports** in `core/ports.py`, written as `typing.Protocol` classes (PEP 544 structural typing, Python's equivalent of Java interfaces: an adapter conforms by having the methods, without inheriting from core):

| Port | Today's adapter | Supplies |
|---|---|---|
| `FundamentalsSource` | `clients/eodhd_client.EODHDClient` + `clients/eodhd_mapper.py` | `CompanyFundamentals` (`core/fundamentals.py`): statements, share counts, dividends, company data, the vendor's labelled market figures |
| `QuoteSource` | `clients/yfinance_client.YFinanceClient` | current quote (price + quote currency), daily closes, year-end matching |
| `RateSource` | `clients/fx_client.FXClient` | current and historical FX rates |

`clients/factory.py` is the composition root: the CLI asks it for one adapter per port and passes them to `load_financial_data`. `CompanyFundamentals` is the whole contract for fundamentals: values as reported, in their **true** currency (the adapter fixes vendor labelling quirks, e.g. EODHD's GBX label on pound-scale LSE values), statement fields `None` when not reported, rows newest first, vendor pre-computed figures only in `MarketData` (display / labelled comparison). `tests/test_architecture.py` fails if an EODHD JSON key appears anywhere in `core/`.

**To replace EODHD with another fundamentals vendor:**
1. Write `clients/<vendor>_client.py` with a class that has `name` and `fetch_fundamentals(ticker) -> CompanyFundamentals`, raising `core.errors` source errors (subclass them for vendor names). Put the JSON-to-model mapping in `clients/<vendor>_mapper.py`, the only place that knows the vendor's field names.
2. Register it in `FUNDAMENTALS_PROVIDERS` (`clients/factory.py`) with the environment variables it needs (`required_env`; the secret ones also in `secret_env`, which are redacted from logs), and set `FUNDAMENTALS_PROVIDER=<vendor>` in `.env`.
3. Map each field with the meanings in `core/fundamentals.py` (and `docs/GRAHAM_METHODOLOGY.md` for which line items Graham needs: net income for the common incl. special items, equity excluding minority interest, reported share counts per year, dividends per share); record every unconfirmed field reading in §11.
4. Run `tests/test_data_source_ports.py` (`assert_fundamentals_contract` on the new mapper's output) and add mapper tests from the vendor's sample payloads; the snapshot scenarios cover the EODHD path end to end.

### 12.1 The free resolution path (`FUNDAMENTALS_PROVIDER=free`)

No paid vendor: `ClientFactory.create_free_source` builds a `RoutingFundamentalsSource` sending `US` (and NYSE / NASDAQ / AMEX) to `FreeUSFundamentalsSource` and every other exchange in `YFinanceClient.EXCHANGE_MAPPING` to a `FallbackFundamentalsSource` of `ForeignSECFundamentalsSource`, then `UnfiledCompanySource` (Yahoo statements + gated Eulerpool history; decision 2026-11-10) (decisions of 2026-11-07, claude-output/SEC_FOREIGN_ROUTE_SCOPE.md); European exchanges (ESEF_EXCHANGES) go to a `FallbackFundamentalsSource`: the SEC route, then `EuropeanFilingsSource`, then `UnfiledCompanySource` for companies with no filings: Yahoo Finance's annual statements, plus (with EULERPOOL_API_KEY) Eulerpool's older years behind the overlap gate (decisions of 2026-11-08 and 2026-11-09, claude-output/EU_XBRL_EULERPOOL_SCOPE.md, claude-output/YAHOO_STATEMENTS_SCOPE.md). Needs `SEC_USER_AGENT` (your name and contact email; the SEC fair-access policy requires it; not a secret, never defaulted).

- **Statements** — SEC EDGAR XBRL companyfacts (`clients/edgar_client.py`, `clients/edgar_mapper.py`): annual from FY2007 (income) / FY2008 (balance sheet), i.e. about 18–19 years until XBRL history accumulates; quarterly for TTM with derived fourth quarters. Latest restated value per year, first-reported differences flagged (GRAHAM_METHODOLOGY §8.7); derived values flagged; per-share figures on today's share basis.
- **CEO fallback** — when Yahoo lists no CEO, the signer of the latest 10-K's Exhibit 31.1 certification (two extra SEC requests), noted.
- **Dividends, splits, profile, market figures** — Yahoo Finance (`clients/yahoo_mapper.py`): payments by ex-date (no pay dates), decades of history; Yahoo industry names (regulated-utility detection works unchanged); market figures display / comparison only.
- **Prices and FX** — unchanged (yfinance).
- **Non-US companies** — those that file 20-F / 40-F (or 10-K) with the SEC, reached through their home listing (`BP.LSE`, `7203.TSE`); on European exchanges (`config/esef_config.py` ESEF_EXCHANGES), a company with no SEC filer is read from its ESEF annual reports on filings.xbrl.org (`EuropeanFilingsSource`: about six years, FY2020 on, plus Eulerpool's earlier years behind the overlap gate when EULERPOOL_API_KEY is set; no Germany, Ireland or AIM; unofficial repository; company-wide IFRS figures only); a `.US` ticker of a 20-F / 40-F filer whose US line trades its shares one for one (ordinary or common shares, or depositary shares each representing one share, read from the annual report cover by `edgar_mapper.registered_line_basis`) goes through `ForeignSECFundamentalsSource.fetch_for_filer`; any other ADR gets no dossier and a pointer to its home listing (its price would need the ADS ratio, which the SEC data does not give). History is the SEC's XBRL: about FY2015 on for IFRS filers, FY2008 on for those with a US-GAAP past. European companies with neither SEC nor ESEF filings (Germany, Ireland, AIM), and companies on any other non-US exchange with no SEC filer (Switzerland, Japan, Australia, Canada, ...; since 2026-11-10), are read from Yahoo Finance's annual statements (`UnfiledCompanySource`), with Eulerpool's gated older years when its key is set.
- **Limits** — `FreeUSFundamentalsSource` serves USD filers only (a non-USD `EdgarAnnualData.currency` raises `TickerNotCoveredError`); companies that file shares / EPS only under their own XBRL tags get N/A per-share figures and a note (Berkshire Hathaway after FY2014, whose filed per-share figures are also in Class A equivalents); other exchanges raise `TickerNotCoveredError` (no dossier) until an adapter is routed; banks have no classified balance sheet (as on the EODHD path); companies reorganised under a new holding company need their predecessor in `config/edgar_config.py` `SEC_PREDECESSOR_CIKS` (the SEC has no structured predecessor link; a Form 8-K12B without a mapping is noted in the dossier).
- **Decisions** — claude-output scope D-F1–D-F7: restated → latest, flagged; shares outstanding → issued − treasury (cover page when both are tagged rounded to millions) → cover page → weighted average; revenue (utilities `Revenues` first; `Revenues` also when a sales tag is under 75% of it; regulated-revenue tags and, for banks, net interest + noninterest income as last resorts; noted when absent) sales tags first, utilities total operating revenues; short-term debt summed; no cache; predecessor filings merged for mapped reorganisations (successor wins where years overlap; D-F6 revised); dividends by ex-date.
- **Adding a market** — write a `FundamentalsSource` for it (same `CompanyFundamentals` contract) and add it to the routes in `create_free_source`.

Ticker symbols stay `SYMBOL.EXCHANGE` with EODHD exchange codes; `YFinanceClient` translates them to Yahoo suffixes (§7). A vendor with other codes translates in its adapter.
